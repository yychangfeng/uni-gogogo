# wit-go 网页版（iPhone / 桌面浏览器）

安卓版 wit-go 的「只读版」。浏览器拿不到教务系统登录后的页面（跨域），所以这里不做自动导入，
改成：**安卓端导出课表文件 → 这里选文件导入**，数据只存在这台设备的浏览器本地。

## 文件

- `index.html`：整个应用（课表渲染、周切换、课程详情、导入文件、关于页），单文件、无外部依赖
- `manifest.webmanifest`：添加到主屏幕用的应用信息
- `sw.js`：离线缓存（装到主屏幕后没网也能看）
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png`：图标

## 部署（GitHub Pages）

1. 把这个 `docs/` 目录提交到仓库 `main` 分支根目录
2. 仓库 Settings → Pages → Source 选「Deploy from a branch」→ Branch 选 `main`、目录选 `/docs` → Save
3. 等 1 分钟左右：`https://yychangfeng.github.io/wit-go/`

## iPhone 上装

1. Safari 打开上面的网址（必须 Safari，微信内打开不行）
2. 底部「分享」→「添加到主屏幕」
3. 之后从桌面图标打开，就是全屏、没地址栏的样子；没网也能看

## 实现方式

- 纯静态单页，托管在 GitHub Pages，没有任何服务端
- 课表存在浏览器 `localStorage`（键 `witgo.kb.v1`），不上传任何地方
- 数据来自安卓版「导出」→「导出为文件」生成的 `wit-go-kb-*.json`
- 装到主屏幕后由 Service Worker 缓存壳资源，离线可用
- 页面里「⋯ → 关于网页版」就是这份说明的用户版

## 局限（和安卓版的差别）

| 功能 | 安卓版 | 网页版 |
| --- | --- | --- |
| 看课表 / 翻周 / 课程详情 | 有 | 有 |
| 从教务系统导入 | 有 | 没有，只能读文件 |
| 上课前 10 分钟提醒 | 有 | 没有（iOS 网页无法定时弹本地通知） |
| 桌面小组件 | 有 | 没有 |
| 成绩查询 / 绩点 | 有 | 没有 |
| 改课加课、主题、分享图片 | 有 | 没有 |

另外：清浏览器数据 / 删图标 / 长期不用被系统回收，本地课表可能丢失——重要课表请留一份 `.json` 备份；
课表是快照，教务系统改了课需要重新导出再导入。
