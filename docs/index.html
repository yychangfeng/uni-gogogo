关于网页版

这是 wit-go 的只读网页版，主要给 iPhone 用。安卓版才是完整版。

它怎么工作

  1. 纯静态页面，托管在 GitHub Pages，没有服务器。
  2. 课表存在浏览器本地（localStorage），不上传任何地方。
  3. 数据来自安卓版「导出」→「导出为文件」得到的 wit-go-kb-*.json，传到这台设备后在这里「选文件」导入。
  4. 装到主屏幕后由 Service Worker 缓存，没网也能打开看。

为什么不能像安卓版那样自动导入

安卓版是自己打开教务系统、在你登录后读屏幕上已经显示的课表。iOS 浏览器里，网页无权读取其它网站（jwxt.wit.edu.cn）的内容，也拿不到那边的登录状态——这是浏览器的跨域限制，不是没做。

所以退一步：安卓版把课表导成文件，这边读文件。

和安卓版差在哪

功能安卓网页
看课表 / 翻周 / 课程详情有有
从教务系统导入有没有，只能读文件
上课前 10 分钟提醒有没有（网页弹不了定时通知）
桌面小组件有没有
成绩查询 / 绩点有没有
改课加课、主题、分享图片有没有

要注意

  • 清浏览器数据、删图标、或长期不用被系统回收，本地课表可能没了——留一份 .json 备份。
  • 只能用 Safari 打开再「添加到主屏幕」，微信里打开装不了。
  • 课表是快照：教务系统改了课，要重新在安卓版导出、再导入。
